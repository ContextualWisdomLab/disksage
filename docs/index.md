# DiskSage

DiskSage is a cross-platform, local-first disk-space manager that inventories reclaimable data and keeps every destructive buyer action behind explicit review and reversible operating-system Trash.

## Current status

DiskSage is in early development. Repository source and open pull requests are candidate evidence until they reach the protected default branch. No public release, hosted application, automatic permanent-delete authority, or production cloud-eviction service is claimed here.

## Product boundary

DiskSage owns local disk inventory, bounded reclaim planning, evidence-backed safety review, and reversible cleanup workflows. Cloud-copy and provider evidence do not by themselves authorize source eviction, and a successful copy is not counted as reclaimed capacity without the documented provider-confirmation and local-eviction gates.
