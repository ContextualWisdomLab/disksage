# DiskSage

DiskSage is privacy-first desktop storage analysis and reclaim decision support for macOS, Windows, and Linux. It helps people understand disk pressure, identify evidence-backed recovery candidates, and see the next safe action without turning age, size, heuristics, or model output into deletion authority.

## Product responsibility

DiskSage owns local storage inventory and evidence-bound reclaim decision support. Optional cloud-provider, ontology, and model integrations may contribute evidence or advice, but they do not become deletion authority. Ambiguous, stale, incomplete, or conflicting evidence fails closed.

## Release and evidence boundary

DiskSage is currently early-development source and has no published GitHub release. A package version, local measurement, passing test, open pull request, candidate byte count, or provider-local copy is not by itself a supported release, production outcome, remote-sync proof, or authorization to remove user data.
